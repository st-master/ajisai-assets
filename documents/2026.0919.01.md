---

**1. 基本的な仕組みと構成**

* **`structure.yaml`（設計図）**
* ディレクトリ構造、生成すべきファイル、初期テンプレート（ヘッダーコメントやデフォルトコード）をデータとして定義。


* **`build.py`（実行エンジン）**
* YAMLファイルを読み込み、指定されたパスにフォルダーを作成。
* ファイルが存在しない場合は新規作成し、定義された初期コードやコメントを書き込む。



---

**2. `structure.yaml` の記述イメージ**

例えば、以下のように階層構造やファイル内容を定義できます。

```yaml
project_name: "my_skeleton_project"
structure:
  - dir: "css"
    files:
      - name: "style.css"
        content: "/* Style definition */\nbody { margin: 0; }"
  - dir: "js"
    files:
      - name: "script.js"
        content: "// Main script file"
  - files:
      - name: "index.html"
        content: "<!DOCTYPE html>\n<html>\n<head><link rel='stylesheet' href='css/style.css'></head>\n<body></body>\n</html>"

```

---

**3. `build.py`（魂を吹き込むスクリプト）の実装例**

Python側で処理する基本的なコード例です。

```python
import os
import yaml

def build_skeleton(config_path):
    with open(config_path, 'r', encoding='utf-8') as f:
        config = yaml.safe_load(f)
    
    base_dir = config.get("project_name", ".")
    os.makedirs(base_dir, exist_ok=True)
    
    def create_items(items, current_path):
        for item in items:
            # ディレクトリの作成
            if 'dir' in item:
                dir_path = os.path.join(current_path, item['dir'])
                os.makedirs(dir_path, exist_ok=True)
                if 'files' in item:
                    create_files(item['files'], dir_path)
            # ルート階層などのファイル作成
            elif 'files' in item:
                create_files(item['files'], current_path)

    def create_files(files, target_dir):
        for file_info in files:
            file_path = os.path.join(target_dir, file_info['name'])
            content = file_info.get('content', '')
            with open(file_path, 'w', encoding='utf-8') as f:
                f.write(content)
            print(f"Created: {file_path}")

    create_items(config.get("structure", []), base_dir)

if __name__ == "__main__":
    build_skeleton("structure.yaml")

```
