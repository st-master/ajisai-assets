# GitHubでの動画ファイルアップロード・LFS対応作業ログ

## 1. 発生していた課題
* Webブラウザ（GitHub画面）からの直接ドラッグ＆ドロップでは、25MBを超えるファイルがアップロードできないエラーが発生。
* Git LFS を導入してプッシュした際、ファイルはアップロードされたものの GitHub Pages 上で動画が再生されず黒い画面のままになってしまう現象が発生。

## 2. 原因
* **Git LFSの仕様:** Git LFS で管理されたファイルは、リポジトリ上には実体ではなく「ポインタファイル（テキストデータ）」として保持されるため、HTML5の `<video>` タグ等で直接動画としてストリーミング再生できない。

## 3. 解決策と実施した手順
ファイルサイズが100MB未満であったため、Git LFSの追跡を解除し、通常のGitファイルとしてプッシュし直すことで正常表示を達成。

1. **Git LFS の追跡解除**

   git lfs untrack "*.mp4"
